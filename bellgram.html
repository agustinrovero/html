BellGram

Project Overview

BellGram is a compact, ultra-flexible IoT notification bridge designed to connect physical input events directly to Telegram instant messaging. Built over an intensive 2-week rapid development cycle, the system leverages an ESP32 microcontroller to immediately alert users via a custom Telegram Bot whenever an event—such as a household doorbell press—is triggered. Designed for maximum usability and zero-friction deployment, BellGram features an onboard web server for easy, app-free provisioning and non-volatile storage, making it an adaptable hardware building block for a wide range of residential, commercial, or industrial alert applications.

The Challenge

Standard smart doorbells and industrial event loggers often rely on proprietary cloud platforms, heavy mobile applications, or hardcoded Wi-Fi credentials requiring complex reflashing to update. Furthermore, interfacing raw microcontroller inputs directly with real-world triggers like household doorbells carries high risk due to signal mismatch and high AC/DC voltage spikes. The objective was to engineer an ultra-compact (32x32 mm), reliable, and universally accessible notification node that safely adapts high-voltage external triggers while keeping setup completely standalone and intuitive.

My Impact & Key Contributions

1. App-Free Onboarding & Native Provisioning

To eliminate hardcoded credentials and third-party smartphone app dependencies, I implemented a native HTTP web server operating directly on the ESP32.
  • Captive Portal / Access Point: If no known network is detected on boot, the board automatically spawns its own Wi-Fi Access Point (AP).
  • Dynamic Parameter Configuration: Users connect via any smartphone or PC browser to set Wi-Fi SSIDs, Passwords, Telegram Bot Tokens, Chat IDs, and custom event messages.
  • Multi-Device Support: Custom alert text per unit allows multiple BellGram nodes to coexist on the same network while dispatching distinct context messages (e.g., "Front Door", "Back Gate", or "Machine Fault"). Re-configuration can be triggered at any time via a dedicated physical button.

2. Robust Non-Volatile Storage (NVS) Architecture

Designed for zero-maintenance operation in volatile power environments.
  • Persistent Configuration: All user parameters (Wi-Fi, tokens, chat IDs, message strings) are committed directly to the ESP32's internal Non-Volatile Storage (NVS) partition.
  • Power-Loss Resiliency: The device configuration persists indefinitely across power outages and hard resets without degradation or the need for re-pairing.

3. Ultra-Compact Hardware & Isolated Input Stage

Engineered an extremely small, low-profile printed circuit board measuring just 32x32 mm (excluding the PCB antenna extension) tailored for seamless integration into tight electrical enclosures or junction boxes.
  • Core Compute: Integrated the ESP32-C3-MINI-1-N4X system-in-package (SiP) for low-power processing, internal flash memory, and built-in Wi-Fi connectivity.
  • Optocoupler Signal Conditioning: Designed 4 optically isolated input channels with associated screw terminal blocks to safely step down and isolate high-voltage signals (commonly present in standard household doorbells or industrial relays) down to 3.3V logic levels.
  • Visual Telemetry & Debugging: Incorporated an addressable RGB LED for intuitive visual status diagnostics (e.g., provisioning mode, Wi-Fi connection, message dispatching).
  • Interface & Breakout: Added a micro-USB connector for power, onboard flashing, and real-time logging, alongside straight pin headers giving direct breakout access to all remaining MCU signals.

Technical Stack

  • Hardware Engineering: Compact Multilayer PCB Design, Component Selection (ESP32-C3-MINI-1-N4X, Optocouplers, Terminal Blocks, RGB LED), Signal Isolation & Conditioning.
  • Embedded Firmware: ESP32 (C/C++), Native Web Server, SoftAP Provisioning Engine, NVS Partition Management, GPIO Interrupt Handling, Telegram Bot API Interfacing.
  • Protocols & I/O: Wi-Fi (802.11 b/g/n), HTTP/HTTPS, RESTful API (Telegram API), Optical Isolation, Addressable RGB Control (WS2812/NeoPixel), Micro-USB Logging.
  • Form Factor: 32x32 mm Ultra-Compact Footprint.

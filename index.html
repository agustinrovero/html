BellGram is an ultra-compact (32x32 mm) IoT notification bridge that connects physical input events directly to Telegram instant messaging using an ESP32-C3 microcontroller. It features four optically isolated input channels to safely step down high-voltage signals from household doorbells or industrial relays. For completely app-free deployment, it hosts a native web server that creates a Wi-Fi Access Point captive portal, allowing users to dynamically configure Wi-Fi credentials, Telegram Bot Tokens, Chat IDs, and custom messages via any browser. All parameters are saved directly to an onboard Non-Volatile Storage (NVS) partition to ensure full data resiliency across power outages.

The Crucero System was a high-performance hardware and software validation platform designed to streamline automotive electronics testing. Built on an ESP32-C6 core, the system features a custom multi-layer PCB with modular CAN nodes, LIN, an 8-channel audio ADC, 8 GPIO, and four DACs for steering wheel control emulation. Its low-level embedded firmware acts as a message-driven OS utilizing COBS packet framing and MessagePack serialization over UART. Controlled via a data-driven Python and PySide6 desktop application, the platform integrates self-describing hardware, a JSON-driven command parser, and real-time telemetry visualization inside a custom 3D-printed enclosure.

The Mirgor Monitoring System was a validation system built to test Volkswagen infotainment components via automated environmental stress testing and multi-channel telemetry. It features a custom multi-layer ESP32 PCB that measures voltage, current, audio levels, and THD inside a rugged housing with a CPC37 connector. Its low-latency C/C++ firmware manages data acquisition, a CAN Bus stack for vehicle simulation, and edge-to-hub streaming across six simultaneous nodes. Driven by a Python master application, the closed-loop system features real-time fault detection and temperature tracking to pinpoint failures immediately during long-endurance certification cycles.

Throughout my career, I have cultivated a strong professional philosophy: I don't just build systems; I create the tools that empower teams to test, refine, and deploy them with confidence. Technical Journey & Expertise

With over 10 years of hands-on experience in product development and technical leadership, I have successfully driven projects from initial architectural design to mass deployment. Some of my most impactful contributions include:

  • IoT & Smart Metering: I spearheaded the development of advanced firmware for smart meters utilizing ESP32 platforms. I engineered custom solutions for reliable data acquisition, low-power optimization, and secure cloud connectivity.
  • Automotive QA Automation: To bridge the gap in complex test environments, I designed and built custom CAN bus automotive simulators. These tools effectively automated quality assurance pipelines, drastically reducing testing bottlenecks and human error.
  • Industrial Control Systems: I have designed deterministic, low-level process controllers utilizing FPGAs, ensuring high-speed execution and precision control for critical industrial operations.
